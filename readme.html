あなたをサポートするAI執事
声にならない「想い」をサルベージします

私を一緒に育ててください

言葉が不明瞭になったり、うまく伝えられないもどかしさを抱えるあなたの「声」を、AIが一生懸命に聞き取ります。

あなたが話してくれるほど、AIはあなたの独特な響きを理解し、より正確に想いを代弁できるよう成長していきます。

ステップ1：Google連携と警告の解除

メール送信機能を使うには、Googleアカウントでの連携が必要です。

⚠️ 赤い警告画面が出た場合

このアプリは開発中のため、Googleより警告が表示されますが、故障ではありません。以下の手順で進んでください。

1. 左下の「詳細」をタップします。

2. 一番下の「tecnocare8-dot.github.io に移動」をタップしてください。

ステップ2：自分と宛先の設定

右上の「tecnocareVoice」ロゴを5回タップして、設定画面を開きます。

ご自身の名前と、送り先（最大5名）の「名前」と「メールアドレス」を登録してください。

💡 重要ルール
メールアドレスが空欄の宛先には、送信ボタンが表示されません。必ずセットで登録しましょう。

ステップ3：想いを届ける

準備ができたら、実際にお話ししてみましょう。

1. ドラムロールでお相手を選んで「決定」します。

2. 赤いボタンを押してお話しします。終わったら画面を「たたた」と叩いてください。

3. AIが汲み取った文章を確認し、緑の「送信」ボタンでメールを届けます！

お楽しみ：100回への道のり

話した回数が10、30、50...と増えるたびに、AI執事から特別なお祝いが飛び出します！
